# Network Project 01: Simple LAN with Switch & PCs

این اولین پروژه عملی من در یادگیری مباحث شبکه و Cisco Packet Tracer است. در این پروژه یک شبکه محلی (LAN) ساده پیاده‌سازی شده است.

## 🛠 تجهیزات استفاده شده
* **Switch:** Cisco 2960-24TT (تعداد: ۱ عدد)
* **End Devices:** PC-PT (تعداد: ۳ عدد)
* **Cabling:** Copper Straight-Through

## 📊 جدول آدرس‌دهی IP (IP Addressing Table)
| Device Name | IP Address | Subnet Mask |
| :--- | :--- | :--- |
| **PC0** | `192.168.1.10` | `255.255.255.0` |
| **PC1** | `192.168.1.20` | `255.255.255.0` |
| **PC2** | `192.168.1.30` | `255.255.255.0` |

## 🧪 تست اتصال (Verification)
ارتباط بین سیستم‌ها با موفقیت از طریق دستور `ping` تست و تایید شد.
